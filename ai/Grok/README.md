# Grok Desktop

Unofficial Electron wrapper for [Grok](https://grok.com).

## Debian

```bash
curl -fsSL https://raw.githubusercontent.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/main/ai/Grok/install.sh | LINUX_DESKTOP_DISTRO=debian sh
```

## Kali Linux

```bash
curl -fsSL https://raw.githubusercontent.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/main/ai/Grok/install.sh | LINUX_DESKTOP_DISTRO=kali sh
```

## Debian Uninstall

```bash
curl -fsSL https://raw.githubusercontent.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/main/ai/Grok/uninstall.sh | sh
```
