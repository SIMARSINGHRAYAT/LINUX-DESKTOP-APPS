# Grok Desktop

Unofficial Electron wrapper for [Grok](https://grok.com).

The installer automatically uses a checksum-verified Node.js 22 runtime when the
system Node.js is missing or too old, so the build does not fail on older Ubuntu,
Debian, or Kali releases. Git and curl are required.

## Ubuntu

```bash
curl -fsSL https://raw.githubusercontent.com/SIMARSINGHRAYAT/LINUX-DESKTOP-APPS/main/ai/Grok/install.sh | LINUX_DESKTOP_DISTRO=ubuntu sh
```
