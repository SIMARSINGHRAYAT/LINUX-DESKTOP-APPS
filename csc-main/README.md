# Linux Desktop Apps

This repository contains scalable Linux desktop applications organized by category. Each application has its own process, persistent session, Flatpak application ID, desktop entry, launcher icon, installer, uninstaller, and build manifest.

## Categories

- [Top 10 AI Developer Apps](Top-10-AI-Developer-Apps/README.md)
- [Streaming Apps](Streaming-Apps/README.md)
- [Microsoft Apps](MICROSOFT-DESKTOP-APPS/README.md)

The applications load the real websites. They do not bundle local kernels, hosted model runtimes, contest judges, streaming media, or service backends. Flatpak keeps each app's files and authentication data isolated.
