# GitHub Desktop

Open Terminal and run:

```bash
sudo apt update
sudo apt install wget
```

Then download the latest `.deb` package:

```bash
wget https://github.com/shiftkey/desktop/releases/latest/download/GitHubDesktop-linux-amd64-3.4.18-linux1.deb
```

Install it:

```bash
sudo apt install ./GitHubDesktop-linux-amd64-3.4.18-linux1.deb
```

Then launch it:

```bash
github-desktop
```

This is the exact copy-paste flow for terminal installation and launch.
